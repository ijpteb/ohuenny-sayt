# Сюда кладите свои 3D-модели и видео

Сайт сам проверяет эти файлы при загрузке. Есть файл — показывается он, нет — заглушка.
Ничего в коде менять не нужно, достаточно перезагрузить страницу.

| Слот        | Где на сайте                 | Модель                       | или видео                   |
|-------------|------------------------------|------------------------------|-----------------------------|
| `console`   | Hero — ретро-консоль         | `models/console.glb`         | `video/console.mp4`         |
| `product-1` | Галерея, 1-й блоб (красный)  | `models/product-1.glb`       | `video/product-1.mp4`       |
| `product-2` | 2-й (голубой)                | `models/product-2.glb`       | `video/product-2.mp4`       |

| `product-6` | 6-й (голубой)                | `models/product-6.glb`       | `video/product-6.mp4`       |
| `hand`      | Финал — указывающая рука     | `models/hand.glb`            | —                           |

Советы:
- Формат моделей — `.glb` (glTF binary). Размер и центр подгоняются автоматически.
- Рука: указательный палец должен смотреть вдоль оси **+Z** модели (в Blender — «вперёд» при экспорте glTF с +Y Up).
- Видео: `.mp4` (H.264), без звука, лучше короткая петля до 5–8 МБ. Показывается как карточка, которая вращается вместе со сценой.
- Тяжёлые модели сжимайте: `npx gltf-transform optimize in.glb out.glb`.
- Названия продуктов, цвета блобов, тексты и почта — в `src/content.js`.
