# Сайт-портфолио студии (скролл-сторителлинг)

Vite + React + three.js (react-three-fiber, drei) + GSAP ScrollTrigger + Lenis.

## Как открыть у себя

Нужен Node.js 18+ (https://nodejs.org).

```bash
cd studio
npm install      # один раз
npm run dev      # откроется на http://localhost:5173
```

На Mac можно просто дважды щёлкнуть `Запустить студию.command` — он сам поставит зависимости,
запустит сервер и откроет браузер. Остановить — закрыть окно Терминала (или Ctrl+C).

Посмотреть с телефона: телефон и компьютер в одной Wi-Fi сети, откройте адрес из строки
`Network: http://192.168.…:5173`, которую печатает `npm run dev`.

Готовая сборка для хостинга: `npm run build` → папка `dist/` (пути относительные, подойдёт любой
статический хостинг, в т.ч. GitHub Pages в подпапке). Проверить сборку: `npm run preview`.

## Что где

| Файл | Что внутри |
|---|---|
| `src/content.js` | название студии, манифест, продукты, цвета блобов, почта |
| `assets/` | **ваши модели и видео** — см. `assets/README.md` |
| `src/sections/*` | секции: Hero, Manifest, Gallery, Final, Header |
| `src/three/*` | 3D-сцены и заглушки (консоль, 6 продуктов, рука) |
| `src/lib/smooth.js` | Lenis + GSAP (плавность: параметр `lerp`, меньше = плавнее) |
| `src/styles.css` | цвета, шрифты, адаптив |

Длина каждой сцены задаётся высотой секции в `styles.css` (`.hero { height: 320vh }` и т.д.):
больше — анимация растягивается на более длинный скролл.
