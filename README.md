# охуенный сайт

https://ijpteb.github.io/ohuenny-sayt/ — надпись по центру экрана, но только пока включён компьютер владельца.

## Как это работает
1. На Mac работает крошечный сервер (`mac/server.py`), он отдаёт надпись и слушает только сам компьютер (127.0.0.1).
2. Программа Cloudflare `cloudflared` открывает к нему «туннель» — временный адрес вида `https://….trycloudflare.com` (без аккаунта; адрес новый при каждом запуске).
3. `mac/run.sh` записывает этот адрес в `docs/tunnel.json` этого репозитория.
4. Страница на GitHub Pages (`docs/index.html`) читает адрес и спрашивает у компьютера надпись. Ответил — показывает её; не ответил (компьютер выключен, спит, нет интернета) — страница пустая. Проверяет раз в 15 с.
5. Автозапуск при входе в систему — launchd (`mac/install.sh`), при сбое перезапускается сам.

После включения компьютера надпись появляется примерно через 1,5–2 минуты (туннель + публикация адреса на Pages); после выключения пропадает в течение ~15 с у открытой страницы и сразу — у новых посетителей.

## Управление
- Включить (и автозапуск): двойной щелчок по `Включить сайт.command`.
- Выключить совсем: двойной щелчок по `Выключить сайт.command`.
- Журнал: `~/Library/Logs/ohuenny-sayt/run.log`.
